# Boundry Mesh

Private networking as a Boundry infrastructure capability: a WireGuard mesh whose authority
(identity, membership, policy, evidence) lives in Boundry's own durable state.

**Status: architecture approved with feasibility gates. Nothing is built yet.**

- [Architecture assessment and roadmap](docs/assessment/boundry-mesh-assessment.md)
- [Gap register](docs/assessment/gap-register.json) (machine-readable)
- [`scripts/host-preflight.sh`](scripts/host-preflight.sh) — read-only host evidence collection

This repository is public. Host observations, addresses and security findings are kept out of it.
